## 1. Team Report

**Status Update for TA:** We successfully deployed the project to Heroku and created the foundation of our web interface. We now have a live website with a functional home page and are preparing to implement core gameplay features.

### 1.1 Goals from Last Week
* **Asset Pipeline:** Begin implementing placeholders for specific characters (e.g., a block for `#`, a spike for `^`). *(In Progress)*

### 1.2 Progress and Issues
* **Progress:**
  * **Heroku Deployment Successful:** Successfully deployed the project to Heroku and established a live public URL for the game.
  * **Live Server Setup:** Learned how to use the live server extension to see real-time changes while editing code, significantly improving our development workflow.
  * **Home Webpage Created:** Built the main homepage with menu options including Levels, Upload Levels, and other navigation buttons.
  * **User Manual Added:** Completed and added user documentation to help future players understand the game concept.
  
* **What Worked:** The Heroku deployment process was smoother than expected. The live server extension has made iterative design much faster since we can see changes instantly.

* **What We Learned:** We learned that Heroku requires specific configuration through the Procfile and that understanding the deployment pipeline early saves time later. We also discovered that CSS styling for game menus requires more attention than typical websites to maintain the gaming aesthetic.

* **Trouble/Stuck:** We're still working on completing the individual pages for each menu option. The menu buttons currently exist but don't navigate to functional pages yet. We need to plan out the structure and content for these pages before implementing them.
