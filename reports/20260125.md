# Project Status Report: Textplorer
**Date:** October 21, 2025  
**Project Phase:** Design & Architectural Planning (Week 2)

---

## 1. Team Report

**Status Update for TA:** The team has officially moved from ideation into **architectural design**. This week was dedicated to resolving our technical stack and mapping out the internal logic of the game before writing production code. We have selected **SFML** as our graphics library due to its robust documentation and cross-platform compatibility. We have also completed our first set of UI wireframes and finalized the "Level Legend" for our ASCII parsing logic.

### 1.1 Goals from Last Week
* **Environment Synchronization:** Finalize graphics library selection. (**Complete: Selected SFML**)
* **Standardize Level Legend:** Define character-to-asset mapping. (**Complete**)
* **Initialize Game Loop:** Create "Skeleton" code. (**Deferred:** We decided to prioritize class architecture diagrams to ensure the "Skeleton" is built on a solid foundation.)

### 1.2 Progress and Issues
* **Progress:** Successfully established a GitHub Projects (Kanban) board to track MVP tasks. Completed low-fidelity wireframes for the main menu and level-loading screens.
* **What Worked:** Using Discord "Stages" for a design charrette helped us quickly agree on a "Neon-Terminal" visual aesthetic.
* **What we Learned:** We realized that a simple 2D array of characters might be too limiting for future features (like moving platforms); we are now designing a `Tile` class to allow for more metadata at specific coordinates.
* **Trouble/Stuck:** We are currently troubleshooting SFML linker dependencies for team members using M1/M2 Macs to ensure everyone can compile the "Skeleton" code next week.

### 1.3 Goals for Next Week (Standup Meeting Agenda)
1.  **The "Hello World" Window:** Every team member must successfully compile a blank SFML window. (Estimate: 2 days)
2.  **File-to-Grid Prototype:** Norman will present the first functional C++ script that reads a `.txt` file and stores it in a 2D vector. (Estimate: 2 days)
3.  **Asset Export:** Drew will provide the first set of 32x32 pixel sprites based on the Level Legend. (Estimate: 1 day)

**Standup Agenda:**
